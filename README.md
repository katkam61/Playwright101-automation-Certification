# Playwright101 Certification Project

This repository contains my Playwright automation assessment created as part of the Playwright 101 certification.
## Tech Stack
- Playwright
- Typescript
- Node.js

## Project Structure
tests/
playwrightAssessment.test.ts
playwright.config.ts

## How to Run
1. Install dependencies:
npm install
2. Run tests:
npx playwright test
3. View report:
npx playwright show-report
